# 测量口径与数据字典

## 预处理

输入 CAMUS NIfTI/MetaImage，或带外部元数据的 AVI。空间间距使用影像头中前两轴的毫米单位；帧率读取 `Info_*.cfg:FrameRate`。NIfTI 第三轴的 `spacing=1` **不代表 1 秒**。时间戳如果来自帧率，保存为 `derived_from_fps`，不冒充采集设备原始时间戳。显式时间戳要求严格递增，与帧数匹配；与帧率差异大于 5% 时拒绝处理。

先用不依赖标签的最大非零连通成像区域保留声窗，移除分离的界面文字/无关区域；也支持手工确认的 keep polygon、排除框及裁剪框。与声窗相连的文字不能保证自动去除，需要通过配置排除和人工核查。原始标注绝不参与裁剪区域估计。每个病例记录保留区域的哈希、像素保留率、是否误删参考前景和待复核标志。默认未人工确认，不能宣称自动完成了所有隐私去标识。

像素中心采用整数坐标，先裁剪后按半像素规则 resize：`x'=(x-x0+0.5)*sx-0.5`，y 同理。JSON 保存 3×3 正反向变换、原始/目标尺寸和缩放后间距。图像双线性，掩膜最近邻插值；专家标注只做几何变换，不能被基于亮度的声窗掩膜清零。评估先将预测掩膜还原到原始尺寸，与**未经缩放的原始 ED/ES 标注**比较。声窗与标注不一致单独标记为待复核，不把标注改成声窗的形状。

## 分割与关键点

模型是 EchoNet 官方采用的 DeepLabV3-ResNet50、单通道 LV 腔输出；CAMUS label 1 作为 LV 腔，其他结构为背景。RGB 接口通过灰度三通道复制适配。官方源码和 MIT 许可保留在 vendor 中。

本地训练是 CAMUS 适配，采用 AdamW、mean BCE、冻结 BN 运行统计、仅训练集归一化。与官方使用 SGD/summed BCE 的精确论文复现区分。未使用测试集选择模型、归一化、阈值和超参数。患者 SHA256 固定自定义 70/15/15 划分；不是官方排行榜划分。

PCA 轮廓几何用于提出心尖、左/右瓣环候选点，假设标准心尖朝图像上方，长轴旋转由 PCA 估计；需要人工审阅，不能称为训练过的解剖关键点检测器。`contour_derived_keypoint_error` 是对专家轮廓执行相同几何算法所得的**代理误差**；真正人工点误差 `manual_keypoint_error` 仅在提供人工点 JSON 时计算。不会把缺失人工标签当作零误差。

人工点文件格式：`{"patient0001_4CH":{"0":{"apex":[x,y],"base_left":[x,y],"base_right":[x,y]}}}`，坐标均为原始像素中心；点标签只用于评价，不输入预测几何。

## 容积与功能

- 单平面面积–长度：`V=8*A_mm2^2/(3*pi*L_mm)/1000`，单位 mL。属于椭球几何近似，不等同于 EF 直接回归。
- 双平面：20 个标准化层面、两个切面的对应直径、较短长轴，`sum(pi*d2*d4/4)*L/20/1000`。此处长度/基底约定为明确的工程实现，必须与专家检查，不能凭同名方法宣称已和临床软件一致。
- CAMUS A2C/A4C 是先后采集。只在同患者同 ED/ES 相位合成双平面结果，不构造同步逐帧双平面容积曲线。
- `SV=EDV-ESV` mL；`EF=100*SV/EDV` 百分点；`CO=SV*HR/1000` L/min，注明为左室总容积差的等效输出，不能无条件当作前向有效流量。
- 半周期不反射、不拼接、不假设收缩期占整周期比例；缺少完整相邻 ED 间期/可靠参考 HR 时，HR、CO、CO MAE 均为 null。
- 质量门控版拒绝不完整/低置信/未确认声窗；原始基线保留数值及质量标志，用于研究误差分析，不能作为临床有效输出。

## 真值层级和评估

输出三种不同口径：①专家 ED/ES 相位下隔离分割误差；②预测容积极值自动选相位的单平面结果；③双平面结果与 `Info.cfg` 的数据集 EF 比较。①②的 EDV/ESV/SV/EF 参考是专家轮廓经同一几何法计算的参考，不冒充独立临床 EDV/ESV 真值。半序列中自动选相位结果也不代表逐搏连续监测已验证。

独立参考可用 JSON 提供：`{"patient0001":{"EDV":120,"ESV":50,"EF":58.33,"SV":70,"HR":60,"CO":4.2}}`。这些为**格式示例，不能用于真实评估**。参考需另行记录来源和同步条件。不能用预测 SV 或相同公式倒推出 CO 真值。CO MAE 仅比较独立提供的 CO。

分割输出 Dice、对称平均边界距离 ASSD、合并双向边界点的 HD95 和最大 Hausdorff，毫米/像素分开；空预测 Dice=0，边界距离不可定义时 null，并保留状态。两侧均为空 Dice=null。功能 MAE 为患者平均绝对误差的总体均值，EF 单位百分点，CO L/min。Bootstrap 以患者为单位。Bland–Altman 仅对预先患者内汇总的差值计算，不能当作逐搏重复测量一致性界限。

时序平滑仅在连续有效片段内执行，不跨缺口插值；同时保留原始和处理后容积，以检查是否压低收缩幅度。完整心搏必须有相邻 ED 峰、内部 ES 和合理 HR。输出有效覆盖率、失败病例、病例数和患者数；不得只展示成功案例。
