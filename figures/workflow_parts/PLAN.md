# 当前项目流程图：方案与零件审阅稿

本轮交付为方法梳理、排版方案与独立零件。**完整总图在讨论并确认后绘制。** 作者已选择：当前 CAMUS 主流程，旁边附贴片扩展；同时用于论文和 PPT。

## 图要表达什么

当前项目是基于公开数据的左室腔分割与几何心功能估算基线：从 CAMUS 二维超声序列出发，仅用专家 ED/ES 帧监督微调分割模型，再由预测掩膜计算几何容积、SV/EF，并按不同参考来源评价。贴片采集作为后续数据接入和外部验证方向，不能用 CAMUS 分数替代贴片验证。

视线从左上角的两切面超声序列进入，沿四个方法分区前进；专家标注另有监督和评价支路。网络不直接预测 EF。

## 当前采用的参考图版式

根据作者新提供的论文流程图重绘零件：参考图以步骤分层、局部横向流程、浅色区域、虚线圆角分组和小标题标签组织内容；真实影像、分割叠加、特征张量、网络分支及几何对象构成主体。旧版竖向文字卡片已由横向图形模块替换。

本轮沿用 **分层步骤 + 浅色分组 + 小标题标签 + 黑色主箭头 + 图形叙事**。A 用浅杏色、B 用浅绿色、C 用浅蓝色、D 用浅黄色、E 用浅紫色；色彩只标识阶段，不表示原创性或性能。特征张量采用参考图中的叠片画法，均为结构示意。完整新参考图仅用于风格分析，没有裁取其中的肿瘤影像、网络、结果曲线或水印。

## 数据流与核心方法核对

| 数据/边 | 当前实际行为 | 实现依据 |
|---|---|---|
| CAMUS → 缓存 | 500 位患者，2CH/4CH 共 1000 条序列、19232 帧；专家 ED/ES 标注共 2000 帧 | 本地 manifest；`src/data/camus/prepare.py` |
| 标签 → 左室前景 | 原标签 0/1/2/3；仅 `label==1` 为左室腔，其余为背景 | `left_ventricle_mask` |
| 影像 → 预处理 | 图像支持区域估计、强度处理、裁剪/缩放至 112×112；标签最近邻；保存原始参考与正反坐标变换 | `prepare_case`；`src/data/transforms.py` |
| 缓存 → 日常入口 | 当前 prepare 入口核验已有缓存与审计并生成三份清单；不自动重新执行原始数据全量处理 | `src/data/prepare.py` |
| 患者 → 互斥集合 | 固定自定义划分 train/val/test=347/71/82；对应监督帧 1388/284/328 | `configs/camus_splits.json`；`src/data/splits.py` |
| 训练帧 → 微调 | 只选 `labeled=True` 的专家帧；训练专用同步增广；灰度复制 3 通道；均值/标准差仅由训练帧求得 | `src/data/base.py`；`src/engine/trainer.py` |
| 预训练 → 网络初始化 | EchoNet 官方分割权重初始化 DeepLabV3-ResNet50；当前是 CAMUS 监督微调 | `configs/experiment.yaml`；`docs/data_sources/echonet_weights.json` |
| 网络 → 参数更新 | 单前景 logit，BCEWithLogitsLoss；AdamW，学习率和衰减均 1e-4；BN 运行统计冻结 | `src/models/`；`src/engine/trainer.py` |
| 验证帧 → 最佳权重 | 验证 BCE 选模，patience=6、min_delta=0.0002；当前最佳轮次 17、23 轮停止 | `src/engine/callbacks.py`；正则化实验记录 |
| 任意序列帧 → 分割 | 逐帧推理，sigmoid，固定 0.5 阈值；无标签的中间帧可被预测，但不加入当前监督损失 | `src/models/build.py`；`src/engine/evaluator.py` |
| 掩膜 → 两条支路 | 原图坐标的原始预测掩膜用于分割评价；几何支路另做最大连通域与填洞 | `evaluate`；`src/geometry/mask_features.py` |
| 几何 → 候选点 | PCA 及基底宽度启发式给出候选心尖/左右基底点，再计算 A、L 和 20 个截面直径 | `infer_landmarks`；`mask_features` |
| 单切面 → 容积 | `V=8A²/(3πL)/1000`，A 为 mm²、L 为 mm，V 为 mL | `single_plane_volume` |
| 两切面 → 容积 | 同患者、同 ED/ES 相位配对；20 个归一化层面，`V=Σπd₂ᵢd₄ᵢ/4 × min(L₂,L₄)/(20×1000)` | `biplane_volume`；`evaluate` |
| 容积 → SV/EF | `SV=EDV−ESV`；`EF=100×SV/EDV`，要求 `0≤ESV<EDV` | `src/geometry/functional.py` |
| 可靠 HR → CO | `CO=SV×HR/1000`；可靠参考 HR 或完整周期才有基础，当前 CAMUS 默认不提供 | `functional`；`detect_beats` |
| 参考 → 分层评价 | 原始专家掩膜用于 Dice/ASSD/HD95；同法轮廓参考与 CAMUS 报告 EF 分开；独立临床参考单列 | `src/metrics/`；`evaluate` |

## 训练、预测与参考在总图中的连接约定

1. **监督支路**：训练子集的 ED/ES 影像与专家二值标签，经配对增广后分别进入网络与 BCE；只有训练损失触发参数更新。
2. **选模支路**：独立验证帧计算验证 BCE，控制早停和最佳权重保存；不对验证数据反向传播。
3. **预测主路**：冻结最佳模型对序列逐帧预测掩膜，再提取几何与参数；预测侧几何不输入人工关键点。
4. **分割评价支路**：只在实际有原始专家标签的 ED/ES 帧，对还原到原坐标的预测进行比较。
5. **功能参考支路**：专家轮廓经同几何法所得参考、CAMUS `Info.cfg` EF、外部独立临床参考分别连接评价层，不混成一个“金标准”。
6. **相位信息**：同法分割误差隔离评价使用参考 ED/ES；另有单平面预测曲线自动极值选相位，两种口径分开，不把参考选相位描述成完全自主识别。
7. **后续贴片支路**：完整连续采集 + 空间/时间标定 + 独立参考 + 跨设备验证，满足条件后接入既有推理与几何路线。默认关闭的质量门控/平滑不画成当前已验证的主模块。

新风格中，虚线只用于分组边界；黑色实线箭头为当前前向数据流，绿色实线箭头为标签监督，青绿色实线曲线为坐标逆变换或参数更新，并由局部文字区分；点线用于条件/待接入路线。专家标签显示为绿色，预测叠加显示为红色；轮廓几何另用浅色填充与线段编码。每一条具有方法含义的有向连接需能在代码或明确的后续方案中找到依据。

## 图注草案

基于 CAMUS 的左室腔分割与几何心功能估算流程。A，保留 ED/ES 专家标注及空间/时间审计信息的二维超声序列，按固定患者划分处理。B，以 EchoNet 官方权重初始化 DeepLabV3-ResNet50，仅用标注帧监督微调，采用训练专用增广、权重衰减与验证早停；最佳权重逐帧生成左室掩膜。C，将掩膜恢复至原图坐标，提取连通区域、轮廓派生候选点及几何特征，按单平面面积–长度法或双平面 20 椭圆盘法估算容积。D，由 EDV/ESV 计算 SV/EF，分层评价结构误差、同法轮廓参考与数据集报告 EF。侧支 E 表示待接入和外部验证的贴片连续采集：具备可靠标定、完整周期及参考数据后，再评价连续 HR/CO。CAMUS 半周期不拼接，贴片扩展不表示已经完成实验验证。
