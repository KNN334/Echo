# 过拟合对照图检查约定

核心问题：固定患者划分和预训练初始化后，正则化方案是否缓解验证损失的后期恶化？

图件主张：本次单种子实验的最低验证 BCE 略低，早停限制继续训练；不声称消除过拟合或证明独立临床有效性。

- 面板 a 为原实验的对照，展示训练损失持续下降而验证损失回升；面板 b 为加入正则化后的记录，展示最佳验证轮次和实际停止位置。两者共同回答同一个问题。
- 使用项目既有 Python / matplotlib 工作流，定量双面板布局，成图宽 183 mm、高 88 mm。正文至少 7 pt，白底蓝/橙配色，颜色同时辅以不同线型。
- 全部 30/23 轮记录均保留，不平滑、不截去后期恶化、不把停止后的空白补成曲线。两面板共用相同坐标范围。
- 训练为批次优化过程的损失，验证为当轮固定权重的损失；新实验训练帧含增广。因此两实验的训练/验证差值不能作为严格可比的泛化差距估计。
- 每个方案仅一次固定种子运行，不制造多种子误差带或显著性结论。数据单位为轮次，患者数写入图注；没有测试损失曲线。
- 保留 PNG 预览、可编辑 PDF/SVG、完整原始曲线 CSV、评估摘要、数据摘要和面板对齐记录。检查最终 PDF 的字号及文字碰撞，并逐面板核对 PNG。

最终实际检查结果在本目录 JSON，人工检查结论在主报告；图件检查不等同医学验证。

实际结果：两面板完整对齐审计 PASS；PDF 字号最低 7 pt，文字碰撞 FAIL=0、WARN=0。PNG 已逐面板目视检查。源码预检提示未提供 TIFF、PNG 为 300 dpi：本次 PNG 用于预览，排版另有矢量稿，尚无指定期刊的 TIFF 投稿要求。
