# v0.4.0 — CAMUS / EchoNet 正式研究基线

完成 500 患者 / 1000 心尖切面的预处理，以官方 EchoNet DeepLabV3-ResNet50 分割权重初始化，在固定自定义患者划分（347 训练 / 71 验证 / 82 测试）上适配训练 30 轮，按最低验证 BCE 选取第 6 轮。不是官方排行榜划分，也不是原论文实验逐项复现。

## 实测

- 测试 82 患者、164 切面、328 个 ED/ES 专家标注帧，失败切面 0。
- 患者平均 Dice 0.9124588；ASSD 1.9438656 mm；HD95 4.7561593 mm。
- 轮廓派生关键点代理误差 5.3927585 mm；无人工解剖点标签，人工关键点误差为空。
- 双平面 EDV / ESV / SV MAE：8.9058365 / 6.1106934 / 8.0487566 mL。
- 双平面 EF MAE：与相同几何法专家轮廓比较 9.6188415 个百分点；与 CAMUS 自带 EF 比较 9.6685370 个百分点。

双平面使用数据集 ED/ES 相位，独立自动极值与单平面结果另列。容积参考是专家轮廓经同一几何方法推导，并非独立临床容积真值。CAMUS 半周期不支持可靠完整周期心率，且无独立 CO 标签，因此 CO、CO MAE 均为空，不作造值。
