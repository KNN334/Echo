# v0.3.1 预处理包已被替代

该版本曾将图像亮度支持区域同时用于清零训练标注。全量审计发现，92 个切面在原始分辨率下有部分专家轮廓处于该区域之外；缩放后的 83 个切面训练掩膜受影响。

请使用 **v0.3.4 或更高版本**：专家标注只做几何裁剪和最近邻缩放，原始专家标注始终完整保留；亮度声窗与参考轮廓的不一致只记录为待审查，不修改标签。

原始 500 患者 / 7,500 文件 CAMUS 数据 Release 不受影响。受影响的本地训练已中止并保存为 `camus_masked_labels_aborted`，不作为正式实验结果；正式训练从官方 EchoNet 权重重新开始，不继承该实验参数。
